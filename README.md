# lab-docker-byAsimanMirza
In this lab you will run the devOpsApp API and a MySQL database together using Docker Compose. You will create a Spring profile for the Docker environment, write a docker-compose.yml that orchestrates both services on a custom network, and verify that the application connects to the database, persists data, and survives container restarts.
